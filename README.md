这是我第一次做复杂项目,具体就是多个模块在多个repo内独立开发最后超级拼装,我也没想好调试该以什么方式进行,暂且就独立docker吧

AAgent的最初问题是qq对话中llm并发会出现上下文不一致、跨对话上下文无法对齐的问题
但后续为方便调试引入了workflow机制
workflow的解析与执行器独立出来成为了这个项目,只需要一个json就可以执行工作流,且可以在数据库中监视状态

但workflow的触发式(一个调用完调下一个)又会破坏上下文一致性,比如在多个workflow以类似协程的工作模式伪并行的时候,以及多agent通过"上下文隔离"(以后可能会设计为通过依赖状态调度而非直接隔离,这种设计和llm权限分层管理有异曲同工)复用的时候。后续将制作hyperCore来解决这个问题
